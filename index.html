What this build covers

Built
  • Upload with authorization note and hash (F-01)
  • Structure detection, profile, warnings (F-02, F-03)
  • Confirm types and roles (F-04)
  • Template questions with explicit plan (F-05, F-08)
  • Result certification (F-17), evidence (F-18), CSV export (F-10, F-16)
  • Reconciliation with passes, buckets, tie-out, review list (F-12 to F-15)
  • Zero network calls, Tier 0 (F-20)
Not in this build
  • AI planner, gateway and spend cap
  • XLSX files, SQL sandbox, independent reference engine in a separate process
  • Split settlements and allocation ledger
  • Custom strategies, saved templates, metric versions
  • Replay, deletion, benchmark, gold cases, accounts
